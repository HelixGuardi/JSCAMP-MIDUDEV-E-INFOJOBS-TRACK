# 📚 Introducción a SQL

Para esta clase hemos creado [aprendesql.dev](https://aprendesql.dev/), una plataforma gratuita para aprender SQL desde cero.

La plataforma incluye ****20 lecciones en total**** para aprender SQL.

Lo interesante es que no se queda solo en la explicación. Al final de las lecciones tienes ejercicios donde puedes escribir consultas directamente y comprobar si la solución es correcta.

Por ejemplo, puedes escribir una consulta como:

```
SELECT * FROM videogames;
```

Y al ejecutarla, la plataforma te indica:

-   Si lo has hecho bien
-   Si hay algún error
-   Cuál es el siguiente ejercicio

Cuando completas todos los ejercicios, se marca tu progreso para que puedas seguir avanzando de forma ordenada.

## 🎨 Una experiencia cuidada y gratuita

Además del contenido, la plataforma está pensada para que resulte cómoda de usar.

Tienes:

-   Diagramas visuales
-   Ejercicios finales
-   Navegación entre lecciones
-   Una experiencia completamente gratuita

La idea es que te sirva como apoyo tanto para esta clase como para seguir aprendiendo por tu cuenta después.

## 🛝 Un playground para practicar lo que quieras

Una de las partes más potentes de [aprendesql.dev](https://aprendesql.dev/) es que también incluye un [playground](https://aprendesql.dev/playground).

Desde ahí puedes experimentar libremente con SQL y hacer pruebas sin miedo.

En este entorno puedes:

-   Crear tablas
-   Hacer consultas
-   Ejecutar SELECT
-   Probar UPDATE
-   Practicar con tus propias ideas

Además, el playground tiene:

-   Modo claro
-   Modo oscuro

Es un espacio pensado para aprender haciendo, que al final es la mejor forma de entender SQL de verdad.

## 🤖 SQL con IA local y privada

Y aquí viene una de las funciones más llamativas de la plataforma: el playground integra inteligencia artificial.

Si tu dispositivo soporta WebGPU, puedes descargar un modelo en local y utilizarlo de forma:

-   100% gratis
-   Privada
-   Local

Eso te permite pedir cosas como:

-   Crear una tabla llamada videogames
-   Generar campos automáticamente
-   Insertar datos de ejemplo

La IA te genera el SQL, puedes ejecutarlo directamente y ver cómo se crean las tablas o se insertan los datos en el acto.

Es una forma muy potente de aprender, porque no solo ves el resultado: también puedes inspeccionar el SQL generado y entender qué está ocurriendo.

## ✍️ Insertar el resultado directamente en el editor

Otro detalle muy útil es que el SQL generado por la IA puede insertarse directamente en el editor del playground.

Eso te permite:

-   Generar una consulta
-   Revisarla
-   Insertarla en el editor
-   Ejecutarla al momento

Así puedes aprender más rápido, experimentar y modificar lo que haga falta sobre la marcha.
